GAS SETUP — BUILD PACK 04 / PITCH MODE
1. Import seed/NC_2027_DEMO_DATABASE.xlsx into Google Sheets.
2. Create a Google Drive folder for demo evidence.
3. Create one Apps Script project and add all .gs files in /gas.
4. Script Properties:
   SPREADSHEET_ID=<Google Sheet ID>
   DRIVE_FOLDER_ID=<Evidence folder ID>
5. Deploy as Web App.
6. Paste deployment URL into frontend/js/config.js.
7. Test:
   - Login all four roles
   - Browser geolocation permission
   - Camera/file evidence
   - Seed Demo
   - Reset Demo
   - Control Center approve/correction
   - Dashboard fallback snapshot
8. For pitching, open the demo once before presenting so browser permissions/caches are ready.
