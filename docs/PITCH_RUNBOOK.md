# Pitch Runbook — 5–7 minutes

## Before the meeting
- Confirm Google Apps Script Web App is reachable.
- Confirm location and camera/file permissions in the demo browser.
- Login once to warm the demo.
- Reset Demo, then Seed Demo.
- Keep a second browser tab on the Executive view.

## Live flow
1. NC Home — Today's PJP
2. Store Alpha — GPS check-in
3. Stock Taking — input + evidence
4. Offtake — input + evidence
5. Store Evidence — photo
6. Complete Visit
7. Quick switch to Data Entry
8. Open an exception and approve/request correction
9. Show Data Quality
10. Quick switch to Analyst
11. Show Target vs Actual and Regional Performance
12. Quick switch to Client
13. Close with Field -> Validate -> Analyze -> Act

## Recovery
If Apps Script/Internet fails, dashboard views automatically show a synthetic offline snapshot. Clearly call it a demo fallback snapshot.
